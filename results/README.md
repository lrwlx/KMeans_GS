# Packaged results

These files are compact summaries and application records from the final
20-seed run. They are included so the manuscript tables can be checked without
downloading the full experiment output.

- `summary/`: 20-seed aggregation, paired tests, leave-one-out, subgroup and
  extra robustness statistics.
- `applications/`: COVID, HLCA, DBpedia and supplementary single-cell records.
- `scaling/`: controlled N/K/d scaling summaries.
- `sensitivity/`: 30-seed sensitivity summary.
- `diagnostics/`: DBSCAN epsilon and seed diagnostics used by the paper.

Raw main-benchmark run records can be regenerated with `run_main_benchmark.sh`.
