# KMeans-GS

Code and results for the Journal of Big Data manuscript
*KMeans-GS: data-calibrated geometric seeding for sample-size-independent
k-means initialization*.

## Layout

- `src/`: seeding, Lloyd, baselines, metrics and dataset loaders.
- `scripts/`: experiment drivers, table/figure builders and the
  supplementary-workbook builder.
- `analysis/`: aggregation and statistical analysis.
- `results/`: per-run raw records, aggregated summaries, scaling, sensitivity
  and application results used by the tables and figures.

## Reproduction

```
pip install -r requirements.txt
python scripts/prefetch_datasets.py
python scripts/run_experiment.py --help
python scripts/make_tables.py
python scripts/make_figures.py
python scripts/build_supplementary.py
```

The dataset identifiers are in `src/datasets.py`. The single-cell atlases are
downloaded from CELLxGENE (Ren et al. 2021, Cell; Sikkema et al. 2023, Nature
Medicine); DBpedia-14 is from Zhang et al. (2015).

The manuscript's Additional file 1 is generated by
`scripts/build_supplementary.py`. Raw per-run records are in
`results/main_tierA/`, `results/main_tierB/`, `results/applications/` and
`results/scaling/`.
